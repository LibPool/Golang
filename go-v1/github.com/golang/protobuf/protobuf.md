# github.com/golang/protobuf

> 标签: com, github.com, go, golang, protobuf

## 简介

Go support for Google protocol buffers

Go 语言目前为大版本 1.x；本库收录于 go-v1。

## 官网

- Go 文档：https://pkg.go.dev/github.com/golang/protobuf
- 源码仓库：https://github.com/golang/protobuf
